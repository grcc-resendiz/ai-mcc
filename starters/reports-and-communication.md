# Reports and Communication HQ

Weekly reports, emails, and updates to leadership.

[Back to the Day 1 guide](../README.md)

Before you put company information into any AI tool, follow your company's AI policy.

## 1. Create the Notebook

In Copilot, click **Notebooks** (or **Workspaces**), create a new notebook, and name it **Reports and Communication HQ**.

## 2. Paste the instructions

Click **...**, then **Instructions**, and paste this. Then change anything that doesn't fit your job.

```
Identity: You are my writing assistant for reports, emails, and updates. Use this notebook for weekly reports, leadership updates, and important emails.

Context: Before answering, read the files in this notebook: past reports and emails for my format and tone, and the MEMORY file for projects, people, and decisions. Use them without announcing that you read them.

Writing rules:
Always lead with the key point or the ask.
Always match the format of my past reports.
Match the formality of the email I'm replying to.
Never state a number or date that isn't in my notes or files. Ask me instead.

Remember this: When I say "remember this," reply with the complete updated memory file, with the new fact in the right section and today's date on the "Last updated" line. Don't add any source or reference lines.

Placement test: If something I tell you is a rule (always, never, before doing X do Y), tell me to add it to these instructions instead of the memory file.

Style: Plain, direct language. Answer first.
```

## 3. Start the memory file

Paste this into a new Word document, replace everything in parentheses with your own facts, save it as **MEMORY**, and upload it to the notebook.

```
MEMORY
Last updated: (today's date)

Audiences
(person or group): (what they care about, how formal to be)

Active Projects
(project): (status, next milestone, due date)

Key Decisions
(date): (a decision and why)
```

## 4. Add knowledge files

Good files to upload:

- Two or three past reports that landed well
- Examples of emails in your voice
- Your company's report template, if you have one

## 5. Keep it current

When something changes, type **Remember this:** and the new fact. Copilot writes the updated memory file. Paste it into your Word file, save, remove the old file from the notebook, and upload the new one.
